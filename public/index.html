About My Project

MyLogin is a simple user authentication website developed using HTML, CSS, Bootstrap, Node.js and MongoDB.

Users can create an account, log in and access their dashboard. The project uses JWT for authentication.

Main Features

Registration

Create a new account using your name, email and password.

Login

Log in to your account using your registered email and password.

Dashboard

View your account details after successful login.
